# JTEC emulator (published site)

Served at https://jtec-emulator.viperecu.com/ by GitHub Pages. The 1997 Dodge Viper JTEC
main-CPU firmware (VIP_2A03) runs in the browser: the emulator's Python is
loaded with [Pyodide](https://pyodide.org/) in a Web Worker.

Generated by `jtec/emulator/publish.py` in the ecu repository; edit the
source there, not here. Files listed in `.ecu-emulator-files.json` are replaced on each
publish.
